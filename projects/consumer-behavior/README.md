# Consumer Behavior & Segmentation Analysis

**Role simulated:** Digital Analyst / Consumer Insights Analyst  
**Dataset:** Synthetic portfolio dataset.

## Business Question
How do audience segments differ in engagement and conversion behavior, and how should lifecycle marketing differ by segment?

## Finding
The strongest-converting segment in this synthetic dataset is **High Intent**.

## Recommendation
Use differentiated lifecycle messaging. New users need onboarding and value education; higher-intent audiences should receive stronger conversion prompts, personalization, and remarketing.
